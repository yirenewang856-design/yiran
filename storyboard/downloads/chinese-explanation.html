五、如何在 Figma 会话中导入

  1. 从 GitHub 下载完整导入包 ZIP 并解压，保留 plugin 与 payloads 文件夹。
  2. 用 Figma 桌面版打开给定文件，确认目标确实是名为 Brain storm 的页面。若实际是区块或画框，本版会停止，不猜测容器、不调整原内容尺寸。
  3. 从 Plugins → Development → New plugin 新建 Figma Design／Custom UI 本地插件。插件 ID 由 Figma 生成；导入包没有编造 ID。
  4. 将包内 code.js、ui.html 复制到新建插件文件夹，保留原 manifest 中 Figma 生成的 id。按 manifest.template.json 配置 main、ui、dynamic-page 和禁止网络访问的字段。
  5. 运行插件，在文件选择中选中 payloads 文件夹的全部 25 个 JSON 文件，确认界面显示 153 个分镜。
  6. 点击英文“Import at the bottom of Brain storm”。导入器按现有页面内容的最下边界，向下留出 240 像素后创建新面板。
  7. 保持 Figma 打开，等待网站证据和本地来源图库完成。来源较多时可能耗时；停止后残留面板会标记为未完成。
  8. 导入完成后仍需人工核对设计候选。程序按名称给出建议，不能证明候选是正确版本或已经验证点击关系。

如果页面缺失／重名，或同名比较面板已经存在，程序会停止而不是覆盖。当前环境只做过语法与模拟 API 检查；没有在真实 Figma 文件中验证插件注册、目标页面、最终渲染和性能。
