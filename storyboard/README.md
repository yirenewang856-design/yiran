## 连贯路线

主线：首页 → Cookie 处理分支 → 2D → 关闭介绍 → 导航 → 主题／数字路径／文章／作品。

功能分支：回到导航或地图 → 搜索、日历、机构信息、订阅、商店、推荐内容、捐赠、账户。3D 从首页另开。

**接受／拒绝 Cookie、多个金额、多个语言、各栏目不是一次不停顿的连续操作；章节中会明确说明何时回到入口。** 保留全部候选状态和复测，不将重复截图冒充新功能。
